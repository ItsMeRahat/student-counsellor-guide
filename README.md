# Student Counsellor গাইডলাইন

AHZ Associates, GEC Chattogram - UK Admission practice guide (একটি HTML ফাইল, কোনো ইনস্টলেশন লাগে না)।

## GitHub-এ পাবলিশ করার ধাপ

1. github.com-এ লগইন করে **New repository** খুলুন (নাম যেমন: `student-counsellor-guide`, Public)।
2. **Add file → Upload files** চাপুন, এই ZIP-এর ভেতরের সব ফাইল (`index.html`, `.nojekyll`, `.github` ফোল্ডার, `README.md`) টেনে দিন, তারপর **Commit changes**।
3. **Settings → Pages → Build and deployment → Source** থেকে **GitHub Actions** বেছে নিন।
4. **Actions** ট্যাবে ডিপ্লয় শেষ হলে লিংক পাবেন: `https://<আপনার-ইউজারনেম>.github.io/student-counsellor-guide/`

পরে `index.html` বদলে আবার Commit করলেই সাইট নিজে থেকে আপডেট হবে।

> `.github` ফোল্ডারটি হিডেন, তাই ফোল্ডারসহ আপলোড করুন (ZIP খুলে পুরো ফোল্ডার টেনে দিন)।
